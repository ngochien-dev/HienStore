# 🛍️ HienStore

> Modern e-commerce platform for fashion & clothing — Built with Spring Boot 3, React 19, TypeScript, Redis, WebSocket

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Spring Boot 3.3 · Java 21 · Spring Security · JWT RS256 |
| Database | MySQL 8 |
| Caching | Redis |
| Real-time | WebSocket (STOMP) |
| Frontend | React 19 · TypeScript · Vite 7 · TailwindCSS 4 |
| State | Redux Toolkit · RTK Query |
| Payment | VNPay |
| AI | Gemini 2.0 Flash (Spring AI) |
| DevOps | Docker · Docker Compose |
